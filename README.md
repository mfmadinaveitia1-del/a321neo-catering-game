# A321XLR Turnaround Lab

Browser-based 3D catering turnaround game (Three.js, single self-contained file, runs offline). Play it on GitHub Pages: open `index.html` or the Pages URL.

- Catering loading-plan HUD: KPIs, loading plan with weight and balance, workflow carousel
- Avatar Automation Mode: Ramp Agent Alex, Catering Lead Maria or the AI Auto-Loader runs the whole turnaround and flight-deck preflight
- Explorable cabin and flight deck with interactive battery, external power and ADIRS controls
